🎯 Overview
A modern full-stack web application for managing employee records with secure authentication and role-based authorization. Built with React, TypeScript, Express, Prisma ORM and SQL Server, this project demonstrates industry-standard practices for building production-ready applications.

✨ Features
Authentication & Authorization
✅ User registration with email validation
✅ Secure login system with JWT tokens
✅ Password hashing using bcrypt (never stores plain passwords)
✅ Role-based access control (User/Admin)
✅ Automatic token expiration and refresh handling
✅ Protected routes with automatic redirect
Employee Management
✅ View all employees in a responsive table
✅ Add new employees with form validation
✅ Edit existing employee information
✅ Delete employees (admin only)
✅ Real-time data updates
✅ Search and filter capabilities
User Interface
✅ Modern Material Design interface
✅ Responsive layout (mobile-friendly)
✅ Intuitive navigation
✅ Error handling with user feedback
✅ Loading states and animations
